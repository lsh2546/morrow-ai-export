# Devpost submission evidence checklist

## Complete

- [x] Deployed functioning product
- [x] Gemini API used in production
- [x] Successful Gemini 3.6 Flash call
- [x] Model, timestamp, status, and latency logged
- [x] Product input and generated result stored
- [x] AI and human execution stages distinguished
- [x] Operations metrics dashboard
- [x] Paid-pilot interest form
- [x] Source code and migration files prepared

## Required before final submission

- [ ] Anonymous/public judge access or clear test credentials
- [ ] GitHub judge access for `testing@devpost.com`
- [ ] GitHub judge access for `judging@hacker.fund`
- [ ] At least one arms-length paying customer
- [ ] Revenue evidence by month
- [ ] Complete P&L including zero or non-zero acquisition spend
- [ ] Customer consent and testimonial
- [ ] Google API usage screenshot
- [ ] Product dashboard and AI/human log screenshots
- [ ] Under-three-minute public demonstration video
- [ ] 500–1000-word English submission narrative
- [ ] Repository testing instructions
